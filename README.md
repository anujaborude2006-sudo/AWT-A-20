## Description

The **Student ID Card Form** is a web application developed using **HTML, CSS, and JavaScript**. It allows users to enter student details, validates the inputs, and generates a personalized Student ID Card dynamically.

------------------------------------------------------------------------

## Features

- Student Registration Form
- Student ID Card Generation
- Input Validation
- Dynamic Content using DOM Manipulation
- Responsive User Interface

------------------------------------------------------------------------

## Technologies Used

- HTML
- CSS
- JavaScript

------------------------------------------------------------------------

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open **index.html** in any modern web browser.
4. Enter the required student details.
5. Click **Generate ID Card** to display the Student ID Card.
